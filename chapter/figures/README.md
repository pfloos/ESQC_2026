# Chapter graphics

This directory contains only the graphics needed by the standalone chapter.
The editable TikZ diagrams and table definitions formerly kept as separate
TeX fragments are now incorporated into `../ESQC_Loos_HF_BF_chapter.tex`.

The transparent porphine cover illustration and all scientific raster/PDF
figures are unchanged. Book covers, the ESQC group photograph and the shared
slide graphics retain their original content; the corresponding slide assets
remain in the repository's `fig/` directory.

`sketch-*.png` are modern AI-assisted portrait illustrations, not archival
photographs. See `../records/portrait-sketches.md` for the subjects, prompts
and limitations. Superseded photographic sources and their permission records
are preserved in `../../archive/photographic-portraits/`, not submitted.

The approved cover's function definitions and editable scene remain in
`../../archive/drafts/cover-studies/06-porphine-exact-gaussians.md`.
