# Chapter graphics

This directory contains only the graphics required by the current chapter. Native TikZ diagrams and table definitions are incorporated into `../ESQC_Loos_HF_BF_chapter.tex`.

The transparent porphine cover, scientific figures and ESQC group photograph are retained unchanged. Original slide assets remain in the repository's `fig/` directory. Book-cover images removed by the author are not chapter inputs.

`sketch-*.png` are modern AI-assisted adaptations of source portraits, not archival drawings. [Sketch prompts and provenance](../records/portrait-sketches.md) and [source-photograph credits](../records/portrait-sources.md) are retained. The superseded source photographs remain recoverable in Git history; removing them from this directory does not change their attribution or permission status.

[Cover definitions, source coordinates and reproduction instructions](../records/cover-illustration.md) accompany the scientific cover renderer.
